# Nexora Gaming

Site vitrine responsive en HTML, CSS et JavaScript, sans framework ni abonnement.

## Fichiers
- `index.html` : structure et contenu du site
- `style.css` : design responsive
- `script.js` : menu mobile, partage et navigation

## Publication gratuite avec GitHub Pages
1. Téléchargez et décompressez `nexora-gaming-site.zip`.
2. Ouvrez votre dépôt GitHub : https://github.com/eudedexteur-netizen/Nexora-gaming-
3. Choisissez **Add file** → **Upload files**.
4. Envoyez les trois fichiers `index.html`, `style.css`, `script.js` à la racine du dépôt et validez avec **Commit changes**.
5. Dans **Settings** → **Pages**, sélectionnez **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.
6. Attendez la publication. L'adresse Pages sera visible dans Settings → Pages.

Aucun service payant ni clé API n'est nécessaire. Le bouton Communauté pourra être relié à Discord, WhatsApp ou TikTok quand vous aurez choisi la destination.
